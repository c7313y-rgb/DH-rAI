# LOCATION SALES AI — 統合立地分析デモ

立地・敷地・建物・交通・商圏・トレンド・類似事例を統合し、売上予測、適正経済条件、出店ニーズ業態、営業アクションを提示する営業向けAIデモです。

## 主な体験

- 7層データによる統合立地スコア
- 保守・基準・上振れの売上予測
- 出店ニーズが高い業態ランキング
- 適正賃料、保証金、フリーレント、投資回収の逆算
- 類似事例比較と評価根拠の可視化
- 商業施設の賑わい創出を含む営業アクション
- AI営業チャットと提案書生成
- PC、タブレット、スマートフォン対応

## 起動

`index.html` をブラウザで開くだけで利用できます。外部APIやビルドは不要です。

ローカルサーバーを利用する場合：

```bash
python3 -m http.server 4173
```

その後 `http://localhost:4173` を開きます。

## デモデータ

表示中の企業名、売上、賃料、スコア、商圏情報は操作体験用のサンプルです。実運用では社内成約実績、物件DB、商圏統計、交通量、競合出退店、地域履歴との連携を想定しています。
